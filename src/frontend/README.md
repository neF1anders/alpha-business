# Фронтенд «Альфа Инсайты»

Прототип ассистента в Альфа-Бизнесе по макетам из Figma
(`vjxsTW9WiBgu2OuJo2EJKM`, страница «Макеты», экраны 01–08) и контракту `docs/api-contract.md`.

## Запуск

Сборки нет: чистые ES-модули, их отдаёт любой статический сервер.

```bash
uv run python -m http.server 5173 --bind 127.0.0.1 -d src/frontend
```

Открыть http://127.0.0.1:5173/. По умолчанию работает **mock-бэк** в браузере.

### Кнопка «Демо» (только в mock-режиме)

Внизу по центру. Позволяет:
- переключить сценарий бэка: обычный / медленно (скелетоны) / нет сигналов / ошибка бэка;
- прислать новый сигнал как SSE-push (новый срочный сигнал запускает пульсацию кнопки ассистента);
- включить ответ чата с низкой уверенностью (`raw_news=true`);
- сбросить данные mock-бэка.

Сценарий запоминается в `localStorage`.

## Что кликабельно

- Левое меню: «Все сервисы» → главная (01), «Лента операций» и «Платежи в работе» → платежи (06),
  «Контрагенты» → 07, «Новый платёж» → 08, остальное → заглушка (04).
- Таблетка ассистента: кнопка открывает панель, индикатор открывает её с фильтром по серьёзности.
- Панель: вкладки «Баннеры / Чат», фильтры, источники (новая вкладка), «Подробнее» (чат с контекстом
  баннера), «Не про меня» и ✕ (`suppress`), «Скрыть баннер» (`dismiss`), ввод вопроса, быстрые вопросы.
- Полоса на страницах действий: «Обсудить» (чат по сигналу), «Скрыть» (`dismiss`, полоса плавно сворачивается).
- Esc или клик по затемнению закрывают панель.

## Анимации

Длительности и кривые — в `styles/tokens.css` (`--dur-*`, `--ease-*`). При `prefers-reduced-motion` они ~0.

- Панель выезжает справа, содержимое догоняет её с задержкой 40–120 мс, фон затемняется плавно.
- Переключатель вкладок со скользящей «плашкой», вкладки сменяются горизонтальным сдвигом с перекрёстным затуханием.
- Карточки: появление лесенкой; при скрытии или фильтрации плавно сворачиваются по высоте;
  push-баннер «раскрывается» сверху и подсвечивается рамкой.
- Счётчики на индикаторах «подпрыгивают» при изменении, срочный push даёт пульсацию кнопки ассистента.
- Чат: сообщения появляются снизу, индикатор «печатает», старые быстрые вопросы сворачиваются после нового вопроса.

## Структура

```
src/frontend/
  index.html              кабинет
  login.html              имитация входа Альфа-Бизнеса + демо-доступ (отдельная страница без shell)
  assets/icons/           SVG-иконки, выгруженные из Figma
  styles/                 tokens (переменные alfa/color из Figma), base, shell, pages, assistant, demo
  src/
    main.js               composition root: выбор API (mock/http), store, service, UI
    config.js             настройки из URL / window.APP_CONFIG
    auth/                 demo-accounts (вымышленные данные), directory, session, context
    login/                страница входа
    api/                  http-client (по контракту), mock-client + mock-data
    state/store.js        маленький observable store
    assistant/
      model.js            типы DTO (JSDoc) и справочники
      service.js          use cases: загрузка, push, suppress/dismiss/seen, чат
      ui/                 rail, drawer, banner-list, banner-card, chat, inline-insight
    ui/                   dom-хелперы, shell (меню и шапка), router, страницы, демо-панель
```

Слои как в бэке: UI зовёт только `service`, `service` работает с API через один интерфейс,
mock и http-клиент взаимозаменяемы.

## Требования к бэку (BFF)

Всё по `docs/api-contract.md`; ниже то, на что фронт уже опирается.

| Что | Где во фронте | Статус в контракте |
|---|---|---|
| `GET /api/companies/{id}/signals` → `{counts, items: BannerDTO[]}` | `service.loadSignals` | есть |
| `counts` по **всем** актуальным баннерам (не только `top_k_serve`) | индикаторы, фильтры | просьба, пока нет |
| `GET /signals/stream` (SSE): события `banners` (BannerDTO[]) и `invalidate` (banner_id[]) | `http-client.subscribeToStream` | просьба |
| после переподключения SSE фронт перечитывает `GET /signals`; после 3 обрывов подряд переходит на поллинг раз в 45 с | там же | — |
| `POST /signals/{id}/seen` (карточка видна в открытой панели ≥ 60%) | `service.markSeen` | есть |
| `POST /signals/{id}/suppress` с телом `{"reason": "not_relevant"}` | «Не про меня», ✕ | есть |
| `POST /signals/{id}/dismiss` без тела | «Скрыть баннер», «Скрыть» на полосе | нужен `hide` в `BannerStore` |
| `GET /signals/inline?page=payments\|counterparties\|new_payment` → `{item, context}` | `inline-insight.js` | просьба |
| `BannerDTO.inline_text` (≤ 2 предложений) для полосы; без него фронт склеивает `headline` + `for_you` | `model.inlineTextOf` | просьба |
| `POST /chat` `{question, banner_id?}` → `ChatAnswer` | `service.ask` | есть |
| `SourceRef.ref_id`, чтобы связать `claim.evidence[].ref_id` с источником | `chat.js` | просьба; без него все источники выводятся под ответом |
| ошибки `{"error", "message"}` с 4xx/5xx | `ApiError` | есть |
| CORS для origin фронта, если BFF на другом порту | — | нужно согласовать |

Поля `BannerDTO`, которые использует фронт: `banner_id`, `severity`, `label`, `headline`, `for_you`,
`caveat`, `raw_news`, `sources[{kind,title,url,ref_id?}]`, `expires_at` (ISO 8601 UTC).
Для `raw_news=true` фронт показывает чип «Новость» вместо `label` и кнопку «Читать источник» (`sources[0].url`).

`company_id` и `role` берутся из `?company=` / `?role=`, иначе из демо-сессии, иначе `demo-company`. Настоящей авторизации нет.

## Отступления от макета

- Вкладки и фильтры в панели отодвинуты от краёв (в Figma вплотную — отмечено там же как недочёт),
  чтобы влез чип «Возможности N».
- Подписи фильтров как в Figma («Внимание / Наблюдения / Возможности»); в черновике описания UI первая — «Предупреждения».
- Добавлены состояния, которых нет в макете: приветствие пустого чата с примерами вопросов,
  ошибка ответа чата с «Повторить», ответ `raw_news` в чате, «в этой категории пока ничего нет» для пустого фильтра.
- Микрофон в поле ввода неактивен (голос вне MVP).
- Фильтр «Скрытые» не сделан: его нет в макете и нет эндпоинта, чтобы вернуть скрытый баннер.

## Ограничения

- Шрифт Inter грузится с Google Fonts; без сети будет системный.
- Вёрстка рассчитана на десктоп от 1100 px (как макет 1280×800), мобильной версии нет.
- Тестов нет: проверено вручную в headless Chrome (все экраны, сценарии демо-панели, анимации).
