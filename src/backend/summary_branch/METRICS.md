# Метрики качества ветки: баннеры, уверенность, генерации

Требование к решению: показать, как мерится качество баннеров, как считается уверенность и как проверяется качество генерации. Все числа ниже взяты из `eval/results/REPORT.md` (методика и таблицы) и `eval/results/PERSONALIZATION.md` (агрегаты по данным организаторов). Данные для оценки синтетические, метки ставил Haiku, поэтому значения предварительные; что не измерено, отмечено прямо.

Пересчёт: `uv run python scripts/eval/tune.py` (отчёт), `uv run python scripts/eval/run_personalization.py --data-dir <каталог>` (персонализация), `uv run pytest` (правила).

## 1. Уверенность: как считается

Уверенность в баннере для компании = ответ на два вопроса (подробно: `summary-branch-dataflow.md`, раздел 5).

- **Верно ли сказано** (одинаково для сегмента): обоснованность утверждений (0.6 × доля чисел, найденных в источнике, + 0.4 × доля общих основ слов), качество источника (первоисточник 1.0, банк 0.9, СМИ 0.6), состав утверждений (выводы без опоры снижают оценку).
- **Касается ли этой компании и актуально ли**: релевантность по профилю (реранкер, чувствительность к теме, отрасль или связь через контрагентов, регион) и свежесть (спад по теме).

Итог — взвешенное геометрическое среднее (веса 0.30 релевантность, 0.35 обоснованность, 0.15 источник, 0.10 свежесть, 0.10 состав), затем предохранители: выдуманное число или слабо подтверждённое утверждение → не выше 0.5; нет источников → баннера нет; компания не чувствительна к теме → не выше 0.45. Решение: ≥ 0.75 баннер, 0.55–0.75 с пометкой, ниже только заголовок и ссылка. Для каждой оценки сохраняются причины.

## 2. Метрики

### 2.1 Качество генерации (валидатор)

| Метрика | Что означает | Значение |
|---|---|---|
| Ложное принятие | доля намеренно испорченных черновиков (подмена или добавление числа, чужой факт, выдуманная сущность, вывод без опоры), прошедших как «высокая» | 56% при старых правилах → **18% (21/117, интервал 12–26%)** с правилами «число должно быть в источнике» и «не менее половины слов совпадает с источником» |
| Ложный отказ | доля честных черновиков, не дошедших до «высокой» | **0/38 (0–9%)** |
| Не ловится | подмена смысла при тех же числах и словах («повысил» вместо «снизил»), выводы без опоры | остаток 18%; NLI не применяем, контроль через промпт |
| Выдуманные числа в живых ответах | утверждения fact/bank с числом, которого нет в источнике | 6/376 = 1,6% |
| Совпадение слов с источником | доля основ слов утверждения, найденных в источнике (живые ответы) | p5 0,78, p25 0,93, медиана 1,00 |
| Неверные утверждения в живых ответах | разметка Haiku, 101 fact-утверждение, проверка выборки вручную | 2/101 (обобщение мнения одного владельца бизнеса) |
| Повторы генерации | доля кластеров, где потребовался второй вызов | 0/23 в финальном прогоне; повтор до 2 попыток при бюджете `full` |

### 2.2 Метрика качества саммари (SQS)

`SQS = 0.45·faithfulness + 0.25·coverage + 0.15·specificity + 0.15·brevity` при пройденной структуре (иначе 0): доля утверждений, подтверждённых источником; сохранность ключевых чисел новости; наличие привязки к признаку компании; длина заголовка ≤ 60 и «для вас» ≤ 140 символов. SQS нужен для сравнения промптов и моделей, в решение о показе не входит.

Финальный живой прогон, 23 кластера: SQS среднее **0,97** (минимум 0,85, максимум 1,0); обоснованность, верность, покрытие и краткость в среднем 1,0; решения: 19 «показать», 4 «с пометкой», 0 скрыто. Средняя уверенность 0,85 (0,67–0,96). SQS ловит выдуманные числа и неполноту, тонкие смысловые искажения не ловит.

### 2.3 Качество персонализации баннеров

560 пар «компания × новость» (20 вымышленных компаний × 28 новостей, метки 0/1/2 «не касается / косвенно / прямо касается» поставлены по профилю).

| Метрика | По тегам (было) | По профилю (стало) |
|---|---|---|
| Шум: баннер показан при метке 0 | 100% (160/160) | **23% (67/295, интервал 18–28%)** |
| Упущено: баннера нет при метке 2 | 0% (0/75) | **2% (2/97, 1–7%)** |
| Среди показанных метка ≥ 1 | 52% | 73% |
| Среди показанных метка 2 | 22% | 38% |
| Средняя уверенность по меткам 0 / 1 / 2 | 0,74 / 0,77 / 0,82 | **0,54 / 0,64 / 0,87** |

Уверенность по профилю монотонна по метке релевантности и разделяет классы; по тегам почти нет. Доля сегментов и охват на базе организаторов (85 513 компаний): 40 сегментов, 10 крупнейших покрывают 85%; ни к одной теме не чувствительны 36%; на 2000 профилях × 28 новостей баннер получают около 28% пар, остальным показывается заголовок и ссылка.

### 2.5 Актуальность и срок жизни

TTL баннера по теме подобран по сроку актуальности новостей: ставка 168 ч, курс 36, труд и спрос 120, остальное 36; кэш саммари 168 ч (`REPORT.md`, раздел 3). Срок актуальности размечен моделью, не пользователями.

### 2.6 Онлайн-метрики (заложены, не измерены)

Нужны реальные клики и обратная связь: доля «полезно», «не про меня», «неточно» (главный сигнал по худшему классу ошибок), раскрытие баннера в чат, доля скрытых баннеров по сегментам. Источники: `BannerStore.mark_seen`, `suppress` с причиной. По ним калибруются веса, пороги и порог чувствительности.

## 3. Ограничения измерений

- Метки синтетические (Haiku), часть проверена вручную (живые ответы), персонализация проверена по правилам согласованности, построчного чтения трети выборки не было.
- Честные черновики в оффлайн-прогоне копируют источник, поэтому ложные отказы смотрит живой прогон (он на 23 кластерах и 72 запросах чата).
- Интервалы Уилсона считают пары независимыми; пары одной компании зависимы, реальная неопределённость шире.
- Не измерены: влияние на поведение пользователей, качество на реальных новостях и профилях, сопоставление валюты новости со странами торговли компании.
